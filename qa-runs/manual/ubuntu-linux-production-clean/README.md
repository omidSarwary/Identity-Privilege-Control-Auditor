# Ubuntu Linux Production Clean Run

This folder contains evidence from a clean Ubuntu VM production run of NordSec Identity & Privilege Control Auditor.

## Test purpose

The purpose of this test was to verify that the Linux production collector works on a real Ubuntu system and that the Python analysis engine correctly evaluates Linux identity, sudo privilege and policy evidence.

This run verifies:

- Linux collector execution
- Linux user collection
- Linux sudo privilege collection
- Linux policy collection
- collector-to-Python JSON flow
- baseline comparison
- risk classification
- alert generation
- report generation
- safe program exit

## Command used

sudo .venv/bin/python app.py --mode linux --linux-log-hours 1 --linux-max-events 100 --no-manual-cross-evidence

## Baseline setup for this run

The approved Linux sudo baseline included:

- omidlab
- secureadmin

The sudo group on the Ubuntu VM included:

- omidlab
- secureadmin
- hacker

The user hacker was intentionally added to the sudo group but was not added to the approved sudo baseline. This was done to verify that the application detects an unapproved Linux sudo user.

## Actual result summary

The application completed successfully.

The run produced:

- Total findings: 3
- Critical findings: 1
- High findings: 2
- Medium findings: 0
- Low findings: 0

The critical finding was:

- hacker: Unapproved Linux sudo user

The high findings were:

- hacker: Inactive account with privileges
- secureadmin: Inactive account with privileges

No policy deviations were reported in this run.
