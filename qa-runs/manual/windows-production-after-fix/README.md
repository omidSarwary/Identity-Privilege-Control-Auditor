# Windows Production After Fix Run

This folder contains evidence from a Windows production run after fixing the Windows local administrator collection issue.

## Test purpose

The purpose of this test was to verify that the Windows collector can correctly collect local administrator membership even when the local Administrators group contains an unresolved/orphaned SID.

A previous Windows production run showed that Get-LocalGroupMember failed with error code 1789. Because of that, local administrators were not marked correctly in windows_identity.csv.

After the fix, the collector should fall back to a more robust method and still collect valid administrator members.

## Test environment

Computer name:

WIN11-01

The test was run from PowerShell as Administrator.

## Baseline setup

The approved Windows administrators baseline included:

- Omidlab
- Administrator

The local Administrators group contained:

- Administrator
- Omidlab
- eviladmin
- one unresolved/orphaned SID

The user eviladmin was intentionally added to the local Administrators group but was not added to the approved baseline.

## Command used

python app.py --mode windows --windows-log-hours 24 --windows-max-events 1000 --no-manual-cross-evidence
