# Windows Test Mode Clean Run

This folder contains evidence from a clean Windows VM test-mode run of NordSec Identity & Privilege Control Auditor.

## Test purpose

The purpose of this test was to verify that the application can run in test mode on a clean Windows environment without reading live system logs.

Test mode uses mock data from tests/mockdata/ and verifies the full Python analysis pipeline:

- fallback loading from mockdata
- JSON and CSV parsing
- risk analysis
- report generation
- alert generation
- safe program exit

## Command used

python app.py --test

## Files in this folder

- console.txt
  Captured terminal output from the test run.

- final_identity_risk_report.txt
  Human-readable audit report generated by the application.

- final_identity_risk_report.json
  Structured JSON version of the audit report.

- executive_summary.txt
  Short summary of the run and the main findings.

- alerts.json
  Structured alert output generated from the findings.

- critical_alerts.log
  Log containing critical findings only.

- python_engine.log
  Python application log for this run.

## Expected result

The expected result is that the application completes all six phases and exits safely.

The console output should show:

[6/6] Safe exit.
